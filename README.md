# OpiOwl

OpiOwl is a Paper 26.1.2 optimization kernel plugin with Folia-compatible scheduling layers.

## Build
- Install JDK 25+
- Run the `build-opiowl` task in VS Code or execute `gradle build`
- Output: build/libs/OpiOwl-26.1-vX.Y.Z.jar

## Commands
- /opiowl status
- /opiowl profile
- /opiowl lagreport
- /opiowl reload

## Configuration
Edit config.yml, then run /opiowl reload.
